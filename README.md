## How it works

`main.py` holds the hype line as a constant, asserts it fits the 1–200 character gate and contains no newline, creates `/output` if needed, and writes the line as UTF-8 bytes to `/output/entry.txt` with no trailing newline. It then prints the character count.

## Run

```bash
python3 main.py
cat /output/entry.txt
```
